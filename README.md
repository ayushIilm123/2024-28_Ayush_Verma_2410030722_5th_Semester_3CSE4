## 📚 Course Curriculum Covered

**Module 1 — Introduction to Modern AI**

- **AI, Machine Learning & Models** — how the three concepts relate, and what "intelligence" means for a system
- **Computer Vision** — object detection, similarity search, image segmentation, optical character recognition (OCR)
- **Machine Translation** — word order, context, idiomatic vs. literal translation
- **Chatbots** — how chatbots generate responses, hallucinations, memory limits, and using multiple chatbots effectively
- **Effective Chatbot Usage** — prompting, fact-checking, summarizing, drafting, mock interviews, and more
- **Generative & Multimodal AI** — image generation and combined image-and-text prompting
- **Skill Stacking** — combining AI literacy with an existing domain skill

**Module 2 — Open Ended Project**
> *Listed in the course curriculum but not completed as part of this submission; no project work is claimed here.*

## 🧠 Skills & Learning Outcomes

- Foundational AI literacy across the core Modern AI concept areas
- Conceptual understanding of how machine learning models relate to broader AI systems
- Awareness of common computer vision tasks and where each is applied in practice
- Understanding of the linguistic challenges behind machine translation
- Insight into chatbot behaviour — including hallucination risk and memory limitations
- Practical habits for writing effective prompts and verifying AI-generated output
- Awareness of generative AI and multimodal prompting capabilities
- A broader perspective on responsible, AI-assisted workflows
